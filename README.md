## 🧭 معرفی

**Cloudflare Scanner** یک اسکنر شبکه با کارایی بالا است که:

| ردیف | قابلیت | توضیح |
|------|--------|-------|
| ۱ | 🔍 اسکن کامل | تمام محدوده‌های IP متعلق به شرکت Cloudflare را اسکن می‌کند |
| ۲ | ✅ تشخیص آنلاین | مشخص می‌کند کدام IPها به پینگ پاسخ می‌دهند (آنلاین هستند) |
| ۳ | 🔌 تست پورت | روی هر IP آنلاین، پورت‌های مختلف را چک می‌کند |
| ۴ | 💾 ذخیره نتایج | نتایج را در ۳ فایل مختلف ذخیره می‌کند |

این ابزار برای **مدیران شبکه**، **پژوهشگران امنیت** و **توسعه‌دهندگان** مفید است.

| ۱ | دانلود پایتون | مراجعه به [python.org/downloads](https://python.org/downloads) |

## 📁 خروجی‌ها

بعد از اجرا، **۳ فایل** در همان پوشه ساخته می‌شود:

| نام فایل | محتوا | مثال |
|----------|-------|------|
| `cloudflare_online_YYYYMMDD_HHMMSS.txt` | لیست همه IPهای آنلاین | `104.18.32.7` |
| `cloudflare_working_YYYYMMDD_HHMMSS.txt` | IPهای دارای پورت باز | `104.18.32.7\|80,443` |
| `cloudflare_results_YYYYMMDD_HHMMSS.json` | گزارش کامل JSON | ساختار یافته با جزئیات کامل |

## ⚙️ تنظیمات

فایل `cloudflare_scanner.py` را باز کنید و این متغیرها را تغییر دهید:

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|---------------|-------|
| `WORKERS` | `200` | تعداد تردهای همزمان (کمتر = کندتر اما سبک‌تر) |
| `BATCH_SIZE` | `500` | هر دسته چند IP پردازش شود |
| `TIMEOUT` | `0.2` | تایم‌اوت پینگ (ثانیه) |
| `DELAY` | `0.001` | فاصله بین دسته‌ها |

```python
WORKERS = 200       # تعداد تردهای همزمان
TIMEOUT = 0.2       # تایم‌اوت پینگ (ثانیه)
PORTS_TO_TEST = [80, 443, 8080, 8443, 2052, 2053, ...]
```

### تنظیم پیشنهادی بر اساس سیستم

| سیستم | WORKERS پیشنهادی |
|-------|------------------|
| لپ‌تاپ قدیمی (۴ هسته) | ۵۰ |
| لپ‌تاپ معمولی (۶ هسته) | ۱۰۰ |
| کامپیوتر قوی (i7/i9) | ۲۰۰ (پیش‌فرض) |
| سرور ابری قدرتمند | ۳۰۰ تا ۵۰۰ |

## 🪟 راهنمای ویندوز

| مشکل | راه‌حل |
|-------|--------|
| `python` شناخته نمی‌شود | در نصب، گزینه **"Add Python to PATH"** را فعال کنید |
| آنتی‌ویروس هشدار می‌دهد | پوشه پروژه را به استثناهای آنتی‌ویروس اضافه کنید |
| اسکن کند است | مقدار `WORKERS` را کاهش دهید (مثلاً ۵۰) |
| خطای دسترسی | برنامه را به صورت **Administrator** اجرا کنید |

### افزایش سرعت در ویندوز

PowerShell را به صورت **مدیر** باز کنید:

```powershell
netsh int tcp set global autotuninglevel=normal
```

## 🔧 عیب‌یابی

| مشکل | راه‌حل |
|------|-------|
| `python not recognized` | پایتون نصب نیست یا PATH تنظیم نشده |
| اسکن خیلی کند است | مقدار `WORKERS` را کم کنید (مثلاً ۵۰) |
| خطای Timeout زیاد می‌شود | اتصال اینترنت را بررسی کنید، `TIMEOUT` را به ۰.۵ افزایش دهید |
| برنامه وسط کار بسته می‌شود | با `Ctrl+C` متوقف کنید و دوباره اجرا کنید |
| فایل خروجی خالی است | صبر کنید تا اولین IP آنلاین پیدا شود |
| آنتی‌ویروس فایل را حذف کرد | پوشه پروژه را به استثناها اضافه کنید |
