## معرفی پروژه

**Cloudflare Scanner** یک اسکنر شبکه با کارایی بالا است که:

- تمام محدوده‌های IP متعلق به شرکت Cloudflare را اسکن می‌کند
- مشخص می‌کند کدام IPها به پینگ پاسخ می‌دهند (آنلاین هستند)
- روی هر IP آنلاین، پورت‌های مختلف را چک می‌کند (HTTP, HTTPS, پورت‌های اختصاصی Cloudflare و ...)
- نتایج را در ۳ فایل مختلف ذخیره می‌کند

این ابزار برای مدیران شبکه، پژوهشگران امنیت و توسعه‌دهندگان مفید است.

## نصب پایتون در ویندوز (گام به گام)

اگر روی ویندوز هستید و پایتون ندارید، این مراحل را انجام دهید:

**مرحله ۱: دانلود پایتون**

به آدرس زیر بروید: https://python.org/downloads/

روی دکمه زرد "Download Python" کلیک کنید.

**مرحله ۲: نصب پایتون**

فایل دانلود شده را باز کنید.

⚠️ خیلی مهم: در صفحه اول نصب، حتماً گزینه "Add Python to PATH" را تیک بزنید (فعال کنید).

سپس روی "Install Now" کلیک کنید.

**مرحله ۳: تأیید نصب**

کلیدهای Win + R را بزنید، cmd را تایپ کنید و Enter بزنید.

در پنجره Command Prompt بنویسید: python --version

اگر چیزی شبیه این دیدید: Python 3.12.2 یعنی نصب درست انجام شده است.

اگر خطا دیدید، یعنی "Add to PATH" را تیک نزده‌اید. پایتون را دوباره نصب کنید و این بار حتماً آن گزینه را فعال کنید.

## اجرای برنامه

روی ویندوز:

python cloudflare_scanner.py

اگر دستور بالا کار نکرد: py cloudflare_scanner.py

اجرا با دابل کلیک: فایل cloudflare_scanner.py را دابل کلیک کنید.

روی لینوکس / macOS:

python3 cloudflare_scanner.py

یا فایل را قابل اجرا کنید:

chmod +x cloudflare_scanner.py
./cloudflare_scanner.py

## خروجی‌های برنامه

بعد از اجرا، ۳ فایل در همان پوشه ساخته می‌شود. اسم فایل‌ها شامل ساعت و تاریخ است، مثلاً:

- cloudflare_online_20250115_143022.txt
- cloudflare_working_20250115_143022.txt
- cloudflare_results_20250115_143022.json

**فایل آنلاین‌ها (online):** لیست همه IPهایی که به پینگ جواب داده‌اند

**فایل کاری‌ها (working):** IPهایی که پورت باز دارند، همراه با شماره پورت‌ها (فرمت: IP|پورت1,پورت2)

**فایل JSON:** تمام اطلاعات به صورت ساختاریافته شامل زمان اسکن، تعداد کل، لیست کامل IPها و پورت‌ها

## تنظیمات قابل تغییر

فایل cloudflare_scanner.py را با Notepad یا هر ویرایشگر متنی باز کنید. در ابتدای فایل این متغیرها را می‌توانید تغییر دهید:

WORKERS = 200       # تعداد تردهای همزمان (کمتر = کندتر اما سبک‌تر)
BATCH_SIZE = 500    # هر دسته چند IP پردازش شود
TIMEOUT = 0.2       # تایم‌اوت پینگ (ثانیه)
DELAY = 0.001       # فاصله بین دسته‌ها

PORTS_TO_TEST = [80, 443, 8080, 8443, 2052, 2053, 2082, 2083, 2086, 2087, 2095, 2096, 8880, 9443, 3000, 5000, 8000, 9000, 22, 3389, 5900]

**تنظیم پیشنهادی برای سیستم‌های مختلف:**

- لپ‌تاپ قدیمی (۴ هسته): WORKERS = 50
- لپ‌تاپ معمولی (۶ هسته): WORKERS = 100
- کامپیوتر قوی (i7/i9): WORKERS = 200 (همان پیشفرض)
- سرور ابری قدرتمند: WORKERS = 300 تا 500

## راهنمای ویندوز

**اگر python شناخته نشد:**

حتماً گزینه "Add Python to PATH" را در نصب فعال کنید. اگر نکردید، پایتون را حذف و دوباره نصب کنید و این بار آن گزینه را تیک بزنید.

**یا از دستور جایگزین استفاده کنید:** py cloudflare_scanner.py

**آنتی‌ویروس هشدار می‌دهد:**

بعضی آنتی‌ویروس‌ها اسکن پورت را suspicious می‌دانند. می‌توانید پوشه پروژه را به استثناهای آنتی‌ویروس اضافه کنید یا هنگام اسکن آنتی‌ویروس را موقتاً غیرفعال کنید.

**افزایش سرعت در ویندوز:**

PowerShell را به صورت مدیر (Administrator) باز کنید و دستور زیر را بزنید:

netsh int tcp set global autotuninglevel=normal

**خطای Permission denied در ویندوز:**

برنامه را به صورت Administrator اجرا کنید: روی cloudflare_scanner.py راست کلیک → Run as administrator

## عیب‌یابی مشکلات رایج

| مشکل | راه‌حل |
|------|-------|
| python not recognized | پایتون نصب نیست یا PATH تنظیم نشده. راهنمای نصب ویندوز را ببینید. |
| اسکن خیلی کند است | مقدار WORKERS را کم کنید (مثلاً ۵۰). |
| خطای Timeout زیاد می‌شود | اتصال اینترنت خود را بررسی کنید. TIMEOUT را به ۰.۵ افزایش دهید. |
| برنامه وسط کار بسته می‌شود | با Ctrl+C متوقف کنید و دوباره اجرا کنید. |
| فایل خروجی خالی است | صبر کنید تا اولین IP آنلاین پیدا شود. |
| آنتی‌ویروس فایل را حذف کرد | پوشه پروژه را به استثناهای آنتی‌ویروس اضافه کنید. |

## سوالات متداول (FAQ)

**س: اسکن کامل چقدر طول می‌کشد؟**

بسته به سرعت اینترنت و سیستم، بین ۵ تا ۱۰ ساعت.

**س: چرا بعضی IPهای آنلاین پورت باز ندارند؟**

خیلی از IPهای کلاودفلر فقط ترافیک خاصی را پاسخ می‌دهند و همه پورت‌ها باز نیست.

**س: آیا این ابزار غیرقانونی است؟**

خیر. آی‌پی‌های کلاودفلر عمومی هستند و پینگ گرفتن و اسکن پورت روی IPهای عمومی در بسیاری از کشورها قانونی است. اما برای اهداف مخرب استفاده نکنید.

**س: چرا آنتی‌ویروس هشدار می‌دهد؟**

چون اسکن پورت توسط بدافزارها هم استفاده می‌شود. این برنامه کاملاً سالم است.

**س: رمز عبور می‌خواهد؟**

خیر.
