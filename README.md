# اسکنر کلاودفلر - ذخیره همه آی‌پی‌های آنلاین

[![Python Version](https://img.shields.io/badge/python-3.7%2B-blue)](https://python.org)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

ابزاری قدرتمند برای اسکن و شناسایی تمام آی‌پی‌های آنلاین کلاودفلر (Cloudflare) و پورت‌های باز روی آن‌ها.

## ✨ ویژگی‌ها

- اسکن تمام محدوده‌های آی‌پی اعلام‌شده توسط کلاودفلر
- شناسایی آی‌پی‌های آنلاین (پاسخ به پینگ)
- تست پورت‌های مختلف شامل HTTP/HTTPS و پورت‌های اختصاصی کلاودفلر
- سرعت بالا با استفاده از چندنخی (Thread Pool)
- ذخیره خودکار نتایج در سه فرمت مختلف
- نمایش لحظه‌ای پیشرفت اسکن
- قابلیت توقف ایمن با Ctrl+C

## 📋 پیش‌نیازها

- **پایتون 3.7 یا بالاتر** (برای ویندوز، لینوکس و مک)
- اتصال اینترنت پایدار

### نصب پایتون در ویندوز

1. به سایت [python.org](https://python.org/downloads/) بروید
2. آخرین نسخه پایتون را دانلود کنید
3. در حین نصب، گزینه **"Add Python to PATH"** را حتماً فعال کنید
4. برای تأیید نصب، Command Prompt را باز کرده و وارد کنید:
   ```cmd
   python --version
