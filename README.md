## معرفی پروژه

**Cloudflare Scanner** یک اسکنر شبکه با کارایی بالا است که:

- تمام محدوده‌های IP متعلق به شرکت Cloudflare را اسکن می‌کند
- مشخص می‌کند کدام IPها به پینگ پاسخ می‌دهند (آنلاین هستند)
- روی هر IP آنلاین، پورت‌های مختلف را چک می‌کند (HTTP, HTTPS, پورت‌های اختصاصی Cloudflare و ...)
- نتایج را در ۳ فایل مختلف ذخیره می‌کند

این ابزار برای مدیران شبکه، پژوهشگران امنیت و توسعه‌دهندگان مفید است.

| 🐧 لینوکس و مک | روی لینوکس و macOS نیز قابل اجراست |

## نصب پایتون در ویندوز (گام به گام)

اگر روی ویندوز هستید و پایتون ندارید، این مراحل را انجام دهید:

**مرحله ۱: دانلود پایتون**

به آدرس زیر بروید: https://python.org/downloads/

روی دکمه زرد "Download Python" کلیک کنید.

**مرحله ۲: نصب پایتون**

فایل دانلود شده را باز کنید.

⚠️ خیلی مهم: در صفحه اول نصب، حتماً گزینه "Add Python to PATH" را تیک بزنید (فعال کنید).

سپس روی "Install Now" کلیک کنید.

**مرحله ۳: تأیید نصب**

کلیدهای Win + R را بزنید، cmd را تایپ کنید و Enter بزنید.

در پنجره Command Prompt بنویسید:

```cmd
python --version
