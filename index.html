🔍 Cloudflare Scanner

اسکنر آی‌پی‌های کلاودفلر

ابزار قدرتمند پیدا کردن همه آی‌پی‌های آنلاین کلاودفلر و پورت‌های باز

🐍 Python 3.7+ 🪟 Windows 🐧 Linux 🍎 macOS 📄 MIT License

📋 معرفی پروژه

Cloudflare Scanner یک اسکنر شبکه با کارایی بالا است که:

  • ✅ تمام محدوده‌های IP متعلق به شرکت Cloudflare را اسکن می‌کند
  • ✅ مشخص می‌کند کدام IPها به پینگ پاسخ می‌دهند (آنلاین هستند)
  • ✅ روی هر IP آنلاین، پورت‌های مختلف را چک می‌کند (HTTP, HTTPS, پورت‌های اختصاصی Cloudflare و ...)
  • ✅ نتایج را در ۳ فایل مختلف ذخیره می‌کند

این ابزار برای مدیران شبکه، پژوهشگران امنیت و توسعه‌دهندگان مفید است.

🪟 نصب پایتون در ویندوز (گام به گام)

✅ مرحله ۱: به آدرس python.org/downloads/ بروید و آخرین نسخه پایتون را دانلود کنید.
✅ مرحله ۲: در حین نصب، حتماً گزینه "Add Python to PATH" را تیک بزنید.
✅ مرحله ۳: برای تأیید نصب، Command Prompt را باز کرده و بنویسید: 
python --version

اوبونتو / دبیان:

sudo apt install python3 -y

فدورا:

sudo dnf install python3

تأیید نصب:

python3 --version

📥 دریافت پروژه

روش ۱ – با Git:

git clone https://github.com/yourusername/cloudflare-scanner.git
cd cloudflare-scanner

روش ۲ – دانلود مستقیم (ZIP): روی دکمه Code کلیک کرده و Download ZIP را انتخاب کنید.

🚀 اجرای برنامه

روی ویندوز:

python cloudflare_scanner.py

روی لینوکس / macOS:

python3 cloudflare_scanner.py

📁 خروجی‌های برنامه

بعد از اجرا، ۳ فایل در همان پوشه ساخته می‌شود:

  • cloudflare_online_YYYYMMDD_HHMMSS.txt - لیست همه IPهای آنلاین
  • cloudflare_working_YYYYMMDD_HHMMSS.txt - IPهای دارای پورت باز (فرمت: IP|پورت1,پورت2)
  • cloudflare_results_YYYYMMDD_HHMMSS.json - گزارش کامل JSON

⚙️ تنظیمات قابل تغییر

فایل cloudflare_scanner.py را باز کنید و این متغیرها را تغییر دهید:

WORKERS = 200       # تعداد تردهای همزمان
TIMEOUT = 0.2       # تایم‌اوت پینگ (ثانیه)
PORTS_TO_TEST = [80, 443, 8080, 8443, ...]  # پورت‌های مورد نظر

  • این ابزار فقط برای آموزش، تحقیق و تست مجاز طراحی شده است
  • از نتایج برای حمله یا نفوذ استفاده نکنید
